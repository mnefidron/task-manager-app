# Система управления задачами (для малых команд)

Приложение "Система управления задачами" — это инструмент для управления задачами в малых командах. Оно позволяет планировать задачи, контролировать их выполнение и визуализировать рабочий процесс через **Kanban-доску** и **календарь**.

---

## 🔧 Назначение
- Планирование задач
- Контроль выполнения
- Визуализация workflow

---

## 📋 Основной функционал

1. **Управление задачами**
   - Создание задач (название, описание, дедлайн, приоритет)
   - Назначение исполнителей
   - Комментарии и файлы в задачах

2. **Визуализация**
   - **Kanban-доска** (To Do / In Progress / Done)
   - **Календарь** с дедлайнами

3. **Уведомления**
   - Оповещения о приближении дедлайна

---

## 🛠 Технические требования

- **Python 3.8+**
- Библиотеки:
  - `customtkinter`
  - `tkcalendar`
